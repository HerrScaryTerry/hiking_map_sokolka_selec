# Public Hikes & GPX Tracks



A clean, interactive web collection of public hiking routes and `.gpx` track files. 



This repository serves two primary purposes:

1. **Interactive Web Viewer:** Webpage hosted via GitHub Pages to visualize routes, view elevation profiles, and explore hike details directly in the browser.

2. **Downloadable GPX Storage:** Centralized host for raw `.gpx` trail files compatible with standard GPS devices and navigation apps (e.g., Garmin, Komoot, AllTrails, OsmAnd).

## How to Use the GPX Files



If you want to use these tracks on your own GPS device or navigation app:



1. Navigate to the `gpx/` directory in this repository.

2. Click on any `.gpx` file to view the route directly on GitHub's built-in map viewer.

3. Click the **Download raw file** button in the top-right corner of the file viewer.

4. Import the downloaded `.gpx` file into your preferred navigation app.
